Project Details

Automated Stock Trading System 🖼️

Goal:

Reduce time spent manually monitoring markets during school by automating a rules-based trading strategy that executes trades autonomously and consistently.

Approach:

Built a system that uses market data APIs to pull real-time stock information, applies custom buy/sell logic based on technical indicators and market conditions, logs every trade decision, and executes transactions automatically. The bot runs on a schedule so you don't have to watch it constantly.

Tech Stack:

Python (or JavaScript), REST APIs (Perplexity, market data providers), task scheduling, data logging, risk management checks.

Impact:

Has generated over $400 in real profit and significantly reduced time spent managing trades during the school week. The system proves the value of combining data analysis with automated execution.

What I Learned:

The importance of defensive programming (handling bad data, edge cases), risk management in any system, and the balance between automation and human oversight. This project taught me that reliable systems don't just work "most of the time"—they need careful design around failure modes.

Automated Cybersecurity Framework for CyberPatriot 🖼️

Context:

CyberPatriot is a nationwide Air Force Association-sponsored competition where students secure multiple virtual machines (Windows and Linux) in a 4-hour window under intense time pressure. Teams earn points for eliminating vulnerabilities and lose points for breaking functionality.

Goal:

Build PowerShell and Bash scripts that automate the repetitive baseline hardening work (password and lockout policy, firewall, services, audit logging, update settings, permissions) so our team can spend its time on the harder, image-specific vulnerabilities.

Tech Stack:

Bash, PowerShell, Linux PAM, UFW, sysctl, systemd, Windows security policy (secedit, auditpol), Windows Defender, VMware snapshots for testing, and Git/GitHub for version control.

Impact:

Our unit's team placed 3rd in the state and 20th nationwide. The scripts speed up baseline security checks, improve consistency under time pressure, and reduce errors from manual repetition, turning a time-consuming manual process into a repeatable one.

Leadership:

As CyberPatriot Co-Commander, I also teach these security concepts to teammates and mentor them through vulnerability analysis, multiplying the impact beyond just my own code.

AI Classroom Helper Bots 🖼️

Goal:

Help classmates understand difficult material by providing explanations tailored to how they learn best, and improve overall workflow efficiency in challenging courses.

Approach:

Built AI-powered bots that take class content (lecture notes, problem sets, textbook excerpts) and generate different types of explanations—conceptual overviews, step-by-step walkthroughs, analogy-based explanations, practice questions. Students can ask for the format that helps them most, rather than a one-size-fits-all explanation.

Tech Stack:

LLM APIs, prompt engineering (designing prompts to elicit different explanation styles), simple backend routing logic, usage logging.

Impact:

Improved understanding and learning efficiency for students who were struggling to keep up with the pace of advanced coursework. By matching explanation style to learning preference, students stay engaged and actually understand concepts rather than just memorizing.

What I Learned:

The real power of AI isn't replacing humans—it's personalizing learning at scale. This project also taught me about prompt design, how small changes in how you ask an AI to respond dramatically change the output quality, and the importance of thinking about educational ethics and preventing misuse.

Impact:
